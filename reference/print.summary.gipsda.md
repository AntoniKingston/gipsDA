# Print a gipsDA model summary

Print a gipsDA model summary

## Usage

``` r
# S3 method for class 'summary.gipsda'
print(x, ...)
```

## Arguments

- x:

  A summary object produced by
  [`summary.gipslda()`](https://antonikingston.github.io/gipsDA/reference/summary.gipslda.md),
  [`summary.gipsqda()`](https://antonikingston.github.io/gipsDA/reference/summary.gipslda.md),
  or
  [`summary.gipsmultqda()`](https://antonikingston.github.io/gipsDA/reference/summary.gipslda.md).

- ...:

  Further arguments passed to printing methods.

## Value

Invisibly returns `x`.
