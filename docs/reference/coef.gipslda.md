# Extract gips LDA discriminant coefficients

Extract gips LDA discriminant coefficients

## Usage

``` r
# S3 method for class 'gipslda'
coef(object, ...)
```

## Arguments

- object:

  A fitted `"gipslda"` object.

- ...:

  Unused.

## Value

The linear discriminant transformation matrix.
